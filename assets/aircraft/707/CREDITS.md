# Boeing 707 model

- **Source:** FlightGear FGAddon, Aircraft/707, downloaded from the official FlightGear aircraft mirror (mirrors.ibiblio.org/flightgear/ftp/Aircraft-2020)
- **Authors:** FlightGear 707 contributors
- **License:** GPL-3.0 (see `LICENSE` in this folder)

## Files used

Models/707.ac, Models/wheels.ac and the texture they reference.

## Changes

None to the files themselves. Machina reads the files at runtime, hides optional, interior or alternate objects, places sub-models with FlightGear's own offsets, and groups the named objects into selectable parts.

These files are distributed under their own license, separately from Machina's code, which is MIT licensed.
