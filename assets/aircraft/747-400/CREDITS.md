# Boeing 747-400 model

- **Source:** FlightGear FGAddon, Aircraft/747-400, downloaded from the official FlightGear aircraft mirror (mirrors.ibiblio.org/flightgear/ftp/Aircraft-2020)
- **Authors:** Gijs de Rooy and the 747-400 contributors
- **License:** GPL-2.0 (see `LICENSE` in this folder)

## Files used

Models/747-400_fuselage.ac, 747-400_wings.ac, 747-400_gear.ac, GE_CF6-80C2B1F.ac and the textures they reference.

## Changes

None to the files themselves. Machina reads them at runtime, hides interior and optional objects, places sub-models with FlightGear's own offsets, and groups the named objects into selectable parts.

These files are distributed under their own license, separately from Machina's code, which is MIT licensed.
