# Boeing 737-800 model

- **Source:** FlightGear FGAddon, Aircraft/737-800, downloaded from the official FlightGear aircraft mirror (mirrors.ibiblio.org/flightgear/ftp/Aircraft-2020)
- **Authors:** FlightGear 737-800 contributors
- **License:** GPL-2.0 (see `LICENSE` in this folder)

## Files used

Models/737-800.ac, LWing.ac, RWing.ac, winglet.ac, VertStab.ac, HorzStab.ac, nosegear.ac and 737-800.png.

## Changes

None to the files themselves. Machina reads the files at runtime, hides interior and optional objects, places sub-models with FlightGear's own offsets, and groups the named objects into selectable parts.

These files are distributed under their own license, separately from Machina's code, which is MIT licensed.
