# Boeing 787-8 Dreamliner model

- **Source:** FlightGear FGAddon, Aircraft/787-8, downloaded from the official FlightGear aircraft mirror (mirrors.ibiblio.org/flightgear/ftp/Aircraft-2020)
- **Authors:** Omega95, Redneck, Jentron, Scotth1, Bicyus, Awexome, Hooray, Zan, Nicky, Thorsten, Oliver T, Joshua W, Makoto Sakaguchi, Thomas Albrecht
- **License:** GPL-2.0 (see `LICENSE` in this folder)

## Files used

Models/787-8.ac and the textures it references.

## Changes

None to the files themselves. Machina reads the files at runtime, hides interior and optional objects, places sub-models with FlightGear's own offsets, and groups the named objects into selectable parts.
