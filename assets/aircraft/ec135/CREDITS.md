# Eurocopter EC135 model

- **Source:** FlightGear FGAddon, Aircraft/ec135, downloaded from the official FlightGear aircraft mirror (mirrors.ibiblio.org/flightgear/ftp/Aircraft-2020)
- **Authors:** Heiko Schulz, Maik Justus, Melchior Franz and contributors
- **License:** GPL-2.0 (see `LICENSE` in this folder)

## Files used

Models/ec135.ac, Models/rotors/mainrotor.ac and the textures they reference.

## Changes

None to the files themselves. Machina reads them at runtime, hides optional or interior variants, places sub-models with FlightGear's own offsets, and groups the named objects into selectable parts.

These files are distributed under their own license, separately from Machina's code, which is MIT licensed.
