# DHC-6 Twin Otter model

- **Source:** FlightGear FGAddon, Aircraft/dhc6 (license in docs/COPYING), downloaded from the official FlightGear aircraft mirror (mirrors.ibiblio.org/flightgear/ftp/Aircraft-2020)
- **Authors:** Syd Adams (initial model), Christian Thiriot (3D, textures), Bo Lan, Jonathan Schellhase, Tim Dicus, Simworld2020, Sascha Reißner
- **License:** GPL-2.0 (see `LICENSE` in this folder)

## Files used

Models/dhc-6.ac, Models/wheels.ac and the textures they reference.

## Changes

None to the files themselves. Machina reads the files at runtime, hides optional, interior or alternate objects, places sub-models with FlightGear's own offsets, and groups the named objects into selectable parts.

These files are distributed under their own license, separately from Machina's code, which is MIT licensed.
