# Shared passenger seat

`cabin_seat.ac` and `737-300-seat.webp`: the 737-300's economy seat (`assets/aircraft/737-300/Models/Seating/`), unmodified, FlightGear 737-300 contributors, GPL-3.0 (LICENSE here).

Models whose FlightGear packages have no passenger cabin carry it in rows (`places` on the file entry: FlightGear offsets merged into one mesh). The rows follow each fuselage's own sections, at real abreast counts, and every seat is checked to sit inside the skin.
