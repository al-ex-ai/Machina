# Shared pilot figures

Unmodified FlightGear pilot meshes, placed in models whose own packages have no pilot (see MODEL_STANDARD.md rule 28).

- `liner_pilot.ac`, `liner_pilot.webp`: from the Tu-134 package (`assets/aircraft/tu134/Models/Pilot/`), Emmanuel Baranger, GPL-2.0
- `general_pilot.ac`, `general_pilot.webp`: from the DR400 package (`assets/aircraft/dr400/Models/Pilot/`), Emmanuel Baranger, GPL-2.0
- `pilotWWII.ac`, `pilotWWII.webp`: from the P-51D package (`assets/aircraft/p51d/Models/Pilot/`), Hal Van Engel and the P-51D contributors, GPL-2.0
- `seat_light.ac`, `seat.webp`: the DR400 crew seat (`assets/aircraft/dr400/Models/Interior/Seats/seat.ac`), unmodified, under the EC135 crew
- `seat_wwii.ac`, `boot.png`: the P-51D pilot seat, the `seat` object copied unmodified out of `assets/aircraft/p51d/Models/Cockpit/P-51D-cockpit.ac`, under the Spitfire's pilot
